Notes

Type naturally — send it, yep, looks good, never mind, skip, buy 10 all work, any case. No keyword is required.

Schedule a friend card by naming a day (“June 15”, “in 3 days”). Pen pal cards ride the next Sunday drop, so they can't be scheduled. Replies mail right away.

The only AI in a normal session is optional “ideas” (note suggestions). Everything else is instant + free.
