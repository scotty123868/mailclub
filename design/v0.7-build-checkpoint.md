## Architecture decisions

### Tab order (final)
`Map · Constellation · [Send FAB centered] · Friends · My Card`

The Send FAB is a centered raised button, NOT a regular tab. Tapping it opens
the SendFlow modal. The Send screen at `app/(tabs)/send.tsx` is being repurposed
as the modal body OR replaced.

### Send icons (from current Mailroom `BottomTabs.tsx`)
- Map: Lucide `Map`
- Constellation: Lucide `Sparkles`
- Send (FAB): Lucide `Send` (paper plane)
- Friends: Lucide `Users`
- My Card: Lucide `User`

### State machine. three gates
WelcomeGate shows the sheet when ANY of these is false:
1. `hasSeenFreeCreditsIntro`
2. `hasCompletedSignup`
3. `hasSentFirstCard` (new in v0.7)

A successful `sendPostcardAction` OR `sendPostcardViaLinkAction` flips #3.

### Forced signup flow (7 screens)
1. Sign in (unchanged. Recraft hero + Apple Sign In + email fallback)
2. Pick photo
3. Write note
4. Pick recipient (4 options: friend / send-link / yourself / pen pal)
5. Their address (or contact info if "send-link")
6. Your address (auto-skip if already on profile)
7. MAILED celebration → enters app

### My Card layout (final)
- Avatar + Name + City  (no "Postcard Friends Since" line)
- Editable bio textarea (replaces About-me grid)
- Stats: Friends · Sent · Received (3, not 4)
- Week-by-week journal gallery fills the rest

### Map interaction (new)
- Full-bleed map with red (sent) + blue (received) pins
- Tap pin → animated dashed Polyline to reciprocal pin
- Bottom sheet slides up with postcard preview card
- Implementation: `react-native-maps` Polyline + `@gorhom/bottom-sheet`

### Constellation port from teteapp
- Source: github.com/scotty123868/teteapp-main/src/lib/constellationGraph.ts + screens/ConstellationScreen.tsx
- Port plan:
  - Copy `constellationGraph.ts` → swap `LocalMoment` for `Postcard`, `participants` for `(sender_id, recipient_id)`
  - Copy `ConstellationScreen.tsx` → swap data source for postcards API
  - Adapt palette: dark sky stays, friend node gradients use Mailroom postal-red/postal-blue/sage
  - Cache settled simulation positions in AsyncStorage by graph-hash for cold-start perf
  - Bottom-sheet drilldown opens postcard detail (existing route)
  - Gold reciprocation ring fires when a node has both outbound + inbound edges

### Pen pal feature
- First-class recipient in screen 4 of the signup-to-send picker
- Copy: "Send one, get one from a stranger"
- Bottom-card CTA on Friends tab
- Backend: random match within tier (city / state / anywhere), opt-in to receive
- Defer matching backend to v0.7.5 if needed. UI placeholder ships in v0.7
