What's in here, what's not

In: proposed designs for the new multi-step send flow (Cover → Inside → Recipient → Delivery → Confirm), a Kindred-inspired stamps pill, four header treatments (with no-wordmark as the lead), a single-line address autocomplete pattern, the postcard back redesign with a QR-code reciprocation loop, and the receiver's magic-link journey.

Not in: production code. Nothing here is built yet. This is the visual review pass before we cut React Native screens. Once you approve direction, we ship in 0.5.0.

Inspiration, not copy: escargot's multi-step pages and "fills their address via our link" pattern are excellent and we steal the structure. The visual skin is fully Mailroom: cream paper, navy serif, red accent, no escargot black.

Buildability check

Yes, this is buildable. Stack: ① Generate unique send_token per Lob send (Supabase row, store sender_id + send_id + token). ② Lob postcard template renders QR with URL https://mailroom.app/r/<token>. ③ Web page at that URL: server-side resolve token → render postcard preview + App Store badge + iOS universal link (deferred deep link via Branch.io or Apple's smart App Banner). ④ On app open with token: edge function consumes token, creates receiver row, inserts sender into receiver's friends, inserts the postcard into receiver's received table. ⑤ App reads token from launch URL, routes to /welcome-mail/<token> screen.

Ship dependencies: domain (mailroom.app), web fallback page (Next.js or static + edge function), universal-links entitlement (already partly configured), Lob template update to include QR + dynamic FROM line, new magic_link_tokens table in Supabase. Estimate: 3–4 days of work for the full loop.

10Message character cap · Lob limits

You asked: what's the word-count limit?

Lob's official limits (4×6 postcard, default template)

  • Hard limit: Lob's API accepts up to ~525 characters in the back message field before rendering breaks the safe area.
  • Practical limit: ~300 characters keeps the text readable at standard print size (10–12pt). Past 350 the type shrinks visibly.
  • Sweet spot: 250–280 chars. About 50 words. Forces brevity, which is the whole point of a postcard.

Recommended cap: 300 characters. Display a live counter as a faint italic at the bottom-right of the message field (mocked in section 03, step 2). Past 280 it goes red.

TODO before ship: confirm with a test Lob send at 300 chars to verify rendering on actual mailed card.

Handwritten font · one default, zero added cost

Cost: Lob charges the same $0.61 per 4×6 postcard regardless of template. Custom HTML is free. Google Fonts are free. Our font choice costs nothing extra.

Pick: Caveat. Warm, legible, doesn't try too hard. One font for every card, no style toggle. Simpler ships.

Implementation: Lob's renderer is Chromium-based. We include <link href="https://fonts.googleapis.com/css2?family=Caveat:wght@500&display=swap" rel="stylesheet"> once in the template HTML. Done forever.
