What changed this session

Brand voice

Slogan + voice cleanup

Real paper. By text.
A magical mail club. Text a photo, mail a moment.

Also updated the landing footer + link-preview OG copy.

Pen pal

Killed "pool" + the Sunday wait

Joining the pool… you're #14 in this week's pool. Flies Sunday.
Matched. Off to a pen pal. Mails the moment there's a match.
Celebration

Flip-as-hero + first-card beat

Photo lands instantly; the card + map are the reveal. A new sender's first card ends with a milestone, not a cold "buy more."

Card flip

Killed the looping GIF

In-thread is calm static stills now. The real flip is a tap/drag-to-flip 3D card on the /c/ page the link opens.

Claim link

Link before note

No-address flow sends the link first (the practical step), note optional after.

P0 · correctness

Sends were silently failing

DB CHECK constraints never allowed the sending / sender-confirm steps, so the send-claim matched 0 rows and every send returned as a "duplicate." Fixed the constraints + status set; advanceState now logs errors.

Batch 1 · security

Webhook forgery guard

LOB_WEBHOOK_SKIP_VERIFY only bypasses signature checks off-production now.

Batch 1 · correctness

Keyword hijack + address parse

A note saying "buy"/"memories" is treated as the note, not a command. The address fast-path stops mis-splitting 123 Main St #4 Denver into a bad city.

Batch 1 · copy

Plain language everywhere

The press is jammed. Sorry for the run-around. ...CO <ZIP>
Couldn't hand this to the printer. Send the full address again with the ZIP on the end.
Batch 2 · money

Atomic credit deduction

One conditional, row-locked UPDATE gates + deducts, so two fast sends can't both win or go negative.

Batch 2 · reliability

Dedup processing-ledger

A crash mid-handle now retries on redelivery instead of black-holing the message. Marks processing → succeeded/failed.
